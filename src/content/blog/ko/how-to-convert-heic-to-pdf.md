아이폰 사진을 HEIC PDF 변환하는 가장 쉬운 방법은 ConvertLime의 [HEIC PDF 변환기](/heic-to-pdf) 같은 무료 브라우저 도구를 쓰는 것입니다. 사진을 순서대로 추가하고, 페이지 크기를 고른 다음, PDF 하나를 다운로드하면 끝입니다. 아이폰, 맥, 윈도우, 안드로이드 어디서나 되고, 사진이 기기 밖으로 나가지 않습니다. 기본 기능으로도 할 수 있습니다. 아이폰은 **파일** 앱, 맥은 **미리보기**, 윈도우는 **Microsoft Print to PDF**를 쓰면 됩니다(윈도우는 먼저 HEIC를 열 수 있어야 합니다). 이 글에서는 방법별 순서와 함께 페이지 순서를 맞추는 요령, PDF 용량을 줄이는 방법까지 알려 드립니다.

## 아이폰 사진은 왜 HEIC일까?

iOS 11부터 아이폰 카메라는 사진을 기본으로 **HEIC** 형식으로 저장합니다. HEIC(High Efficiency Image Container)는 JPG와 같은 화질을 절반 정도의 용량으로 담는 형식이라, 아이폰에 사진을 훨씬 많이 넣을 수 있습니다. 문제는 사진을 다른 곳에 보낼 때입니다. 관공서, 학교, 회사, 보험사 서류는 대부분 PDF를 요구하고, 윈도우 PC나 웹사이트 업로드 창에서는 HEIC가 아예 열리지 않는 경우가 많습니다. 형식에 대한 자세한 설명은 [HEIC 파일이란?](/blog/what-is-a-heic-file)에 있습니다.

PDF로 만들면 두 문제가 한 번에 해결됩니다. 어느 기기에서나 똑같이 보이고, 여러 장의 사진을 파일 하나로 묶을 수 있기 때문입니다. 신분증 앞뒷면, 모아 둔 영수증, 손으로 쓴 신청서, 종이 계약서를 찍은 사진 등에 딱 맞습니다.

## ConvertLime으로 HEIC PDF 변환하기 (모든 기기)

1. Safari, Chrome, Edge, Firefox 중 하나로 [HEIC PDF 변환기](/heic-to-pdf)를 엽니다.
2. HEIC 사진을 상자 안으로 끌어 놓거나, 상자를 눌러 사진 보관함이나 폴더에서 고릅니다.
3. 페이지 크기를 고릅니다.
   - **이미지와 같게** – 모든 페이지가 사진과 똑같은 모양이 되고 흰 여백이 생기지 않습니다. 화면으로 볼 때 좋습니다.
   - **A4** – 일반 용지 크기입니다. 사진은 작은 여백을 두고 가운데에 놓이며, 원래 크기보다 늘어나지 않습니다. 인쇄하거나 공식 서류로 낼 때 좋습니다.
4. **PDF 다운로드**를 누릅니다. 사진이 한 장씩 각 페이지에 들어간 PDF 하나가 저장됩니다.

모든 작업이 브라우저 안에서 이뤄지므로 신분증, 계약서, 진단서처럼 중요한 서류에도 안심하고 쓸 수 있습니다. 가입도, 장수 제한도, 워터마크도 없습니다. 확장자가 `.heic`가 아니라 `.heif`인 사진은 [HEIF PDF 변환](/heif-to-pdf)을, HEIC·JPG·PNG가 섞여 있다면 [이미지 PDF 변환](/image-to-pdf)을 쓰세요.

## 페이지 순서를 제대로 맞추는 요령

여러 페이지짜리 서류는 순서가 중요합니다. ConvertLime은 파일을 추가한 순서대로 페이지를 만듭니다. 다음을 기억해 두세요.

- **순서가 중요하면 한 장씩 추가하기**: 1페이지, 2페이지 순으로 차례대로 넣습니다.
- **폴더에서 한꺼번에 고를 때는 파일 이름부터 바꾸기**: `01.heic`, `02.heic`처럼 번호를 붙여 두면 편합니다.
- **실수했다면 X 버튼으로 지우고 다시 추가하기**: 다시 추가한 사진은 목록 맨 뒤로 갑니다.

저장하기 전에 다운로드 버튼에 표시되는 페이지 수를 보고 빠진 사진이 없는지 확인하세요.

## 아이폰에서 HEIC를 PDF로 변환하기

아이폰만으로 만들려면 **파일** 앱을 쓰면 됩니다.

1. **사진** 앱에서 사진을 고르고 **공유**를 누른 뒤 **파일에 저장**을 선택합니다. '나의 iPhone' 같은 폴더를 고르세요.
2. **파일** 앱을 열고 저장한 폴더로 갑니다.
3. **더 보기** 버튼(점 세 개)을 누르고 **선택**을 눌러 사진을 고릅니다.
4. 오른쪽 아래 **더 보기** 버튼을 누르고 **PDF 생성**을 선택합니다.

같은 폴더에 새 PDF가 생깁니다. 페이지는 폴더의 정렬 순서를 따르므로, 먼저 이름순이나 날짜순으로 정렬해 두세요. 단계를 줄이고 싶다면 Safari에서 [HEIC PDF 변환기](/heic-to-pdf)를 열고, 상자를 눌러 사진 보관함에서 바로 고른 뒤 다운로드하는 편이 빠릅니다.

## 맥에서 HEIC를 PDF로 변환하기

맥은 HEIC를 기본으로 열 수 있어서 **미리보기**로 충분합니다.

1. Finder에서 HEIC 사진을 모두 선택하고, 오른쪽 클릭한 다음 **다음으로 열기 → 미리보기**를 고릅니다.
2. 왼쪽 사이드바에서 사진을 원하는 순서로 끌어 놓습니다.
3. **파일 → 프린트**를 클릭합니다.
4. 왼쪽 아래 **PDF** 메뉴를 열고 **PDF로 저장**을 고릅니다.

최신 macOS에는 더 빠른 방법도 있습니다. Finder에서 사진을 선택하고 오른쪽 클릭한 뒤 **빠른 동작 → PDF 생성**을 고르면 됩니다. 페이지는 Finder의 정렬 순서를 따릅니다.

## 윈도우에서 HEIC를 PDF로 변환하기

가장 번거로운 건 윈도우입니다. 윈도우 10과 11은 Microsoft Store에서 **HEIF 이미지 확장**과 유료인 **HEVC 비디오 확장**을 설치해야 사진 앱에서 HEIC를 볼 수 있습니다. 설정 방법은 [윈도우에서 HEIC 파일 여는 방법](/blog/how-to-open-heic-files-on-windows)에 정리해 두었습니다. HEIC가 열리면 다음과 같이 합니다.

1. **파일 탐색기**에서 사진을 선택하고 오른쪽 클릭한 뒤 **인쇄**를 고릅니다(윈도우 11에서는 먼저 **추가 옵션 표시** 클릭).
2. 프린터를 **Microsoft Print to PDF**로 바꿉니다.
3. 사진 가장자리가 잘리지 않게 하려면 **사진을 프레임에 맞추기** 체크를 해제합니다.
4. **인쇄**를 누르고 파일을 저장합니다.

아무것도 설치하거나 결제하고 싶지 않다면, Edge나 Chrome에서 [HEIC PDF 변환기](/heic-to-pdf)를 열면 HEIC 사진을 바로 읽을 수 있습니다.

## PDF 용량은 얼마나 될까?

HEIC는 워낙 효율이 좋아서, PDF로 만들면 원본 사진보다 커지는 경우가 많습니다. PDF 안에서는 사진이 고화질 JPEG로 저장되므로, 아이폰의 1200만 화소 사진이라면 한 페이지에 2~4MB 정도가 될 수 있습니다. 열 페이지만 돼도 메일 첨부나 온라인 제출 용량 제한을 쉽게 넘깁니다.

PDF를 가볍게 하려면 이렇게 해 보세요.

- **사진을 먼저 압축하기**: [이미지 압축기](/compress-image)로 사진을 줄인 다음 [JPG PDF 변환](/jpg-to-pdf)으로 합칩니다. 좋은 설정은 [화질 저하 없이 이미지 용량 줄이는 법](/blog/how-to-reduce-image-size-without-losing-quality)에서 설명합니다.
- **긴 서류는 나누기**: 제출 양식의 용량 제한이 엄격하면 PDF를 두세 개로 나눕니다.
- **불필요한 배경 잘라내기**: 변환 전에 사진을 잘라서 꼭 필요한 부분만 남깁니다.

PDF가 필요 없고 다른 기기에서 사진을 열기만 하면 된다면 [HEIC JPG 변환](/heic-to-jpg)이 더 간단합니다. 일반 JPG 사진을 PDF로 만들고 싶다면 [JPG PDF 변환 방법](/blog/how-to-convert-jpg-to-pdf) 가이드도 참고하세요.
