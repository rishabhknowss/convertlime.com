JFIF 파일이란 확장자가 `.jpg` 대신 `.jfif`로 붙은 평범한 JPEG 그림입니다. JFIF는 **JPEG File Interchange Format**의 줄임말로, JPEG 그림을 저장하는 표준 방식을 뜻합니다. 안에 든 그림은 다른 JPG와 똑같고, 저장할 때 윈도우가 이름표만 다르게 붙였을 뿐입니다. 그래서 JFIF 파일은 PC에서는 잘 열리지만, `.jpg`나 `.jpeg`만 찾는 일부 업로드 양식에서는 거부됩니다.

## 그림이 .jfif로 저장되는 이유

보통 윈도우에서 웹 브라우저의 그림을 오른쪽 클릭해 저장할 때 생깁니다. 윈도우는 파일 종류마다 어떤 확장자를 쓸지 목록으로 갖고 있습니다. 어떤 컴퓨터에서는 JPEG 그림에 대한 설정이 `.jpg` 대신 `.jfif`로 되어 있는데, 다른 프로그램이 이 설정을 바꿔 놓은 경우가 많습니다. 브라우저는 이 설정을 따르기 때문에 내려받은 파일이 `.jfif`로 끝납니다.

그림에는 아무 문제가 없습니다. 같은 그림, 같은 화질, 같은 픽셀 크기입니다.

## JFIF, JPG, JPEG 비교

| | .jfif | .jpg | .jpeg |
| --- | --- | --- | --- |
| 그림 종류 | JPEG | JPEG | JPEG |
| 화질 | 같음 | 같음 | 같음 |
| 브라우저와 사진 앱에서 열림 | 예 | 예 | 예 |
| 업로드 양식에서 받아 줌 | 안 될 때가 있음 | 예 | 예 |
| 주로 생기는 곳 | 윈도우에서 내려받을 때 | 카메라, 휴대폰, 웹사이트 | 일부 카메라와 앱 |

`.jpg`와 `.jpeg`는 완전히 같습니다. 둘 사이를 바꾸고 싶다면 [JPG JPEG 변환](/jpg-to-jpeg)이나 [JPEG JPG 변환](/jpeg-to-jpg)을 쓰세요.

## JFIF 파일을 JPG로 바꾸는 세 가지 방법

가장 쉬워 보이는 방법을 고르세요. 세 가지 모두 일반 JPG가 됩니다.

### 방법 1: 온라인에서 무료로 변환하기

웹사이트에서 파일이 계속 거부되거나, 그림이 많을 때 가장 확실한 방법입니다.

1. 무료 [JFIF JPG 변환기](/jfif-to-jpg)를 엽니다.
2. JFIF 그림을 상자에 끌어다 놓거나, 상자를 눌러 고릅니다.
3. 그림이 한 장씩 브라우저 안에서 제대로 된 JPG로 저장됩니다. 아무것도 업로드되지 않습니다.
4. **다운로드**를 누르거나 ZIP 파일로 한 번에 받습니다.

### 방법 2: 파일 이름 바꾸기

JFIF 파일에는 이미 JPEG 그림이 들어 있어서, 이름만 바꿔도 보통 됩니다.

1. 윈도우에서 파일 탐색기를 열고 **보기** 메뉴에서 **파일 확장명**을 켜서 `.jfif`가 보이게 합니다.
2. 파일을 오른쪽 클릭하고 **이름 바꾸기**를 고릅니다.
3. `.jfif`를 `.jpg`로 바꾸고 **Enter**를 누릅니다.
4. 확장자를 바꾸면 문제가 생길 수 있다는 경고가 뜨면 **예**를 누릅니다.

맥에서는 Finder에서 파일 이름을 클릭해 확장자를 `.jpg`로 바꾸고, **'.jpg' 사용**을 눌러 확인합니다.

### 방법 3: 그림판이나 미리보기에서 사본 저장하기

- **윈도우:** 그림판에서 파일을 열고 **파일 → 다른 이름으로 저장 → JPEG 그림**을 고른 뒤 저장합니다.
- **맥:** 미리보기에서 파일을 열고 **파일 → 내보내기**에서 포맷을 **JPEG**로 정한 뒤 저장합니다.

그림을 다시 저장하는 방법이라 한두 개에는 괜찮지만, 폴더 전체를 바꾸기에는 느립니다.

## 윈도우가 그림을 JFIF로 저장하지 않게 하는 방법

원인은 윈도우 레지스트리의 설정 하나입니다. 레지스트리를 잘못 고치면 문제가 생길 수 있으니, 자신 있을 때만 바꾸세요. 잘 모르겠다면 생길 때마다 이름을 바꾸거나 변환하면 됩니다.

1. **Windows + R**을 누르고 `regedit`을 입력한 뒤 **Enter**를 누릅니다.
2. `HKEY_CLASSES_ROOT\MIME\Database\Content Type\image/jpeg`로 갑니다.
3. 오른쪽에서 **Extension**이라는 값을 두 번 클릭합니다.
4. `.jfif`를 `.jpg`로 바꾸고 **확인**을 누릅니다.
5. 레지스트리 편집기를 닫고 브라우저를 다시 시작합니다.

이제 새로 내려받는 그림은 `.jpg`로 저장됩니다. 이미 저장한 파일은 `.jfif` 그대로이니 이름을 바꾸거나 변환하세요.

## PNG나 PDF가 필요하다면?

신청서가 JPG가 아닌 다른 것을 요구할 때도 있습니다.

- **PNG가 필요하다면** [JFIF PNG 변환](/jfif-to-png)을 쓰세요. JPEG 그림으로 만든 PNG는 파일이 더 커지고, 투명 배경이 생기지는 않습니다.
- **문서가 필요하다면** [JFIF PDF 변환](/jfif-to-pdf)으로 그림 한 장 이상을 PDF 파일 하나에 담으세요.
- **파일이 너무 크다면** 변환한 뒤 [이미지 압축](/compress-image)에 JPG를 넣거나, 신청서가 정확한 용량을 요구하면 [200KB로 줄이기](/resize-image-to-200kb)를 쓰세요.

## JFIF 파일은 안전한가요?

JFIF 파일은 다른 JPG와 마찬가지로 그림일 뿐입니다. 확장자 자체가 위험 신호는 아니고, 윈도우 설정이 반영된 것뿐입니다. 다른 파일과 마찬가지로, 믿을 수 있는 사람과 웹사이트에서 받은 그림만 여세요.

## 짧게 정리하면

JFIF 파일은 확장자가 조금 특이한 JPEG 그림입니다. 이름을 `.jpg`로 바꾸거나, 그림판이나 미리보기에서 사본을 저장하거나, 무료 [JFIF JPG 변환기](/jfif-to-jpg)로 몇 초 만에 깔끔한 JPG를 얻을 수 있습니다. 다른 낯선 확장자도 만나셨다면 [AVIF 파일](/blog/what-is-an-avif-file)과 [HEIC 파일](/blog/what-is-a-heic-file) 가이드에서 설명해 드립니다.
