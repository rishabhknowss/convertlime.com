PNG PDF 변환을 가장 빨리 하는 방법은 브라우저를 쓰는 것입니다. ConvertLime의 [PNG PDF 변환기](/png-to-pdf)를 열고 PNG 파일을 넣은 뒤, 페이지 크기를 고르고 **PDF 다운로드**를 누르면 끝이에요. 윈도우, 맥, 아이폰, 안드로이드 어디서나 똑같이 쓸 수 있고, 파일이 기기 밖으로 나가지 않습니다. 컴퓨터나 휴대폰에 기본으로 들어 있는 기능으로도 할 수 있어요. 윈도우는 **Microsoft Print to PDF**, 맥은 **미리보기**, 아이폰은 **파일** 앱입니다. 이 글에서는 방법별 순서와 함께, 투명 PNG가 PDF에서 어떻게 보이는지, 페이지 순서를 맞추는 요령까지 정리했습니다.

## PNG를 PDF로 바꾸면 좋은 경우

PNG는 컴퓨터와 휴대폰에서 **화면 캡처**를 하면 저장되는 형식입니다. 스캔 앱이나 디자인 프로그램도 PNG를 자주 씁니다. 글씨가 또렷하게 남는 장점이 있지만, 이미지 열 장을 따로따로 보내기는 번거롭죠. PDF 하나로 묶으면 이런 때 편합니다.

- **열 장이 파일 하나로.** 이체 확인 화면, 카톡 대화 캡처, 영수증, 스캔한 계약서 페이지를 한 번에 보낼 수 있어요.
- **제출처가 PDF만 받을 때.** 채용 사이트, 은행, 학교, 정부24 같은 온라인 민원은 PDF만 받는 경우가 많습니다.
- **깔끔하게 인쇄돼요.** PDF는 페이지 크기가 고정되어 화면에서 본 그대로 인쇄됩니다.
- **어디서나 열려요.** 휴대폰, 컴퓨터, 메일 앱 모두 따로 설치할 것 없이 PDF를 보여 줍니다.

## 브라우저에서 PNG PDF 변환하는 방법

1. [PNG PDF 변환기](/png-to-pdf)를 엽니다.
2. PNG 파일을 상자 안으로 끌어다 놓거나, 클릭해서 고릅니다. 클립보드에 있는 캡처를 **Ctrl + V**(맥은 **Cmd + V**)로 바로 붙여 넣을 수도 있어요.
3. 페이지 크기를 고릅니다.
   - **이미지와 같게** – 페이지가 PNG와 똑같은 크기가 됩니다. 줄어드는 게 없어서 화면으로 볼 캡처에 잘 맞아요.
   - **A4** – 여백이 조금 있는 표준 용지 크기입니다. 스캔한 서류, 인쇄할 문서, 관공서에 제출할 파일에 알맞아요. 큰 이미지는 페이지에 맞게 줄어들고, 작은 이미지는 늘어나지 않습니다.
4. **PDF 다운로드**를 누릅니다. PNG가 한 장씩 각각의 페이지로 들어간 파일 하나가 저장됩니다.

회원가입, 워터마크, 개수 제한이 모두 없습니다. PDF는 브라우저 안에서 만들어지기 때문에 계좌 정보나 신분증이 찍힌 캡처도 서버로 가지 않아요. PNG, JPG, 아이폰 사진이 섞여 있다면 [이미지 PDF 변환](/image-to-pdf)을 쓰세요.

### 페이지 순서를 맞추는 요령

페이지는 파일을 추가한 순서대로 들어갑니다. PNG 여러 개를 한꺼번에 고르면 보통 파일 이름 순으로 들어가니, 미리 `01-앞면.png`, `02-뒷면.png`처럼 이름을 바꿔 두면 좋습니다. 한 장이 엉뚱한 자리에 들어갔다면 **X** 버튼으로 빼고 다시 추가하세요. 맨 뒤로 이동합니다.

## 투명 PNG는 PDF에서 어떻게 될까?

PNG는 로고나 배경을 지운 서명처럼 투명한 부분을 가질 수 있습니다. PDF 페이지는 종이처럼 보이도록 만들어지기 때문에, ConvertLime은 각 PNG를 **흰 배경** 위에 올려서 넣습니다. 서명이나 로고 모양은 그대로이고, 체크무늬 대신 흰 종이 위에 놓인다고 생각하면 됩니다.

PDF 안에서 각 이미지는 고화질 JPG(품질 92%)로 저장됩니다. 덕분에 PNG 데이터를 그대로 넣을 때보다 파일이 훨씬 가볍고, 캡처 속 글씨도 선명하게 남아요. 웹사이트용처럼 투명한 그대로 써야 하는 이미지는 PNG 원본을 남겨 두세요.

## 윈도우에서 PNG를 PDF로 변환하기

윈도우 10과 11에는 **Microsoft Print to PDF**라는 가상 프린터가 들어 있습니다.

1. **파일 탐색기**에서 PNG를 하나 고르거나, **Ctrl**을 누른 채 여러 개를 클릭합니다.
2. 마우스 오른쪽 버튼을 눌러 **인쇄**를 고릅니다(윈도우 11은 먼저 **추가 옵션 표시**).
3. 프린터를 **Microsoft Print to PDF**로 바꾸고 **전체 페이지 사진** 같은 레이아웃을 고릅니다.
4. 캡처 가장자리가 잘리지 않도록 **프레임에 맞게 사진 조정** 체크를 해제합니다.
5. **인쇄**를 누르고 파일 이름을 정한 뒤 **저장**합니다.

단점은 가로로 긴 캡처가 인쇄 창에서 잘리거나 작아지기 쉽다는 점입니다. 글씨가 잘린다면 브라우저 변환기에서 **이미지와 같게**를 고르는 편이 확실합니다.

## 맥에서 PNG를 PDF로 변환하기

1. Finder에서 PNG를 고르고 마우스 오른쪽 버튼을 눌러 **다음으로 열기 → 미리보기**를 고릅니다.
2. 왼쪽 사이드바에서 썸네일을 끌어 순서를 맞춥니다.
3. 한 장이면 **파일 → PDF로 내보내기**. 여러 장이면 **파일 → 프린트**를 누르고 왼쪽 아래 **PDF** 메뉴에서 **PDF로 저장**을 고릅니다.

미리보기는 안정적이지만, 프린트를 거치면 이미지가 용지 크기 페이지에 놓이기 때문에 캡처 둘레에 흰 여백이 생길 수 있습니다.

## 아이폰에서 PNG를 PDF로 변환하기

1. 캡처가 **사진** 앱에 있다면 골라서 **공유**를 누르고 **파일에 저장**을 고릅니다.
2. **파일** 앱에서 **선택**을 눌러 이미지를 고르고, **더 보기**(점 세 개) → **PDF 생성**을 누릅니다.

사진 앱에서 이미지를 고른 뒤 **공유 → 프린트**에서 미리보기를 두 손가락으로 벌리면 PDF로 공유할 수도 있어요. 두 방법 모두 되지만 순서를 마음대로 맞추기는 조금 어렵습니다. Safari에서 [PNG PDF 변환기](/png-to-pdf)를 열면 이미지를 순서대로 골라 PDF를 바로 파일 앱에 저장할 수 있습니다.

## PDF 용량이 너무 클 때

고해상도 캡처를 여러 장 넣은 PDF는 몇 MB가 되기도 해서, 업로드가 막힐 수 있습니다. 간단한 해결법은 두 가지예요.

- **A4**를 고르세요. 아주 큰 이미지는 페이지에 맞게 줄어듭니다.
- 먼저 [이미지 압축 도구](/compress-image)로 PNG를 가볍게 만든 뒤 PDF로 바꾸세요.

추천 설정은 [화질 저하 없이 이미지 용량 줄이는 방법](/blog/how-to-reduce-image-size-without-losing-quality)에서 설명합니다. 캡처가 아니라 카메라로 찍은 사진을 PDF로 만들려면 [JPG PDF 변환 방법](/blog/how-to-convert-jpg-to-pdf)도 참고하세요.
