HEIC 파일이란 **High Efficiency Image Container**(고효율 이미지 컨테이너) 형식으로 저장된 사진을 말합니다. iOS 11부터 아이폰과 아이패드의 기본 사진 형식이라, 아이폰으로 찍은 사진 이름이 `.heic`로 끝난다면 바로 이 때문입니다. HEIC 사진은 JPG와 똑같이 선명하면서 용량은 절반 정도입니다. 문제는 윈도우, 많은 웹사이트, 오래된 프로그램에서 열리지 않는다는 점입니다.

가장 빠른 해결책은 어디서나 열리는 JPG로 바꾸는 것입니다.

## 아이폰은 왜 HEIC를 쓰나요?

애플이 HEIC로 바꾼 이유는 저장 공간을 아끼기 위해서입니다. 1,200만 화소 아이폰 사진 한 장이 HEIC로는 약 1.5~2MB, JPG로는 3~4MB 정도인데, 눈으로 보면 차이가 없습니다. HEIC는 파일 하나에 여러 장의 이미지를 담을 수도 있어서, 라이브 포토와 연속 촬영 사진도 이 방식으로 저장됩니다.

## HEIC 파일이란 형식이 왜 안 열릴까요?

HEIC는 특허 사용료가 걸린 HEVC(H.265) 코덱을 씁니다. 그래서 지원하는 곳과 지원하지 않는 곳이 들쭉날쭉합니다.

| 여는 곳 | HEIC가 열리나요? |
| --- | --- |
| 아이폰, 아이패드, 맥(사진, 미리보기) | 예 |
| 윈도우 10 / 11 사진 앱 | 유료 HEVC 확장을 설치해야 가능 |
| 크롬, 엣지, 파이어폭스 | 아니요 |
| 구글 포토, 드롭박스 | 예, 미리보기로 보여 줍니다 |
| 입사 지원서, 비자, 시험 접수 사이트 | 대부분 거부 |
| 워드, 파워포인트, 오래된 포토샵 | 안 되는 경우가 많음 |

## HEIC 파일을 JPG로 바꾸는 방법

1. 무료 [HEIC JPG 변환기](/heic-to-jpg)를 엽니다.
2. HEIC 사진을 상자에 끌어다 놓거나, 상자를 눌러 파일에서 사진을 고릅니다.
3. 사진 한 장당 1초 정도면 브라우저 안에서 바뀝니다. 사진이 어디에도 올라가지 않습니다.
4. **다운로드**를 누르세요. 여러 장을 넣었다면 **전체 ZIP으로 다운로드**를 누르면 됩니다.

투명 배경이나 화질 손실 없는 사본이 필요하다면 [HEIC PNG 변환](/heic-to-png)을 쓰세요. 여러 장을 문서 하나로 보내야 한다면 [HEIC PDF 변환](/heic-to-pdf)이 편합니다.

## 변환하지 않고 HEIC 파일 여는 방법

- **윈도우:** Microsoft Store에서 *HEVC 비디오 확장*을 설치하면(약 0.99달러) 사진 앱에서 HEIC가 열립니다.
- **맥:** 파일을 두 번 클릭하면 미리보기에서 바로 열립니다.
- **안드로이드:** 구글 포토와 최신 갤러리 앱 대부분에서 HEIC를 볼 수 있습니다.

사진을 보내거나 사이트에 올리기만 하면 된다면, 무언가를 설치하는 것보다 변환하는 쪽이 더 빠릅니다.

## 아이폰에서 HEIC로 찍히지 않게 하는 방법

1. **설정**을 엽니다.
2. **카메라**를 누르고 **포맷**으로 들어갑니다.
3. **높은 호환성**을 고릅니다.

이제부터 찍는 사진은 JPG로 저장됩니다. 또한 아이폰은 사진을 이메일로 보내거나 애플 기기가 아닌 곳으로 옮길 때 HEIC를 자동으로 JPG로 바꿔 줍니다. **설정 → 사진 → Mac 또는 PC로 전송**을 **자동**으로 맞춰 두세요.

## 파일 이름만 .heic에서 .jpg로 바꾸면 안 되나요?

안 됩니다. 이름을 바꾸면 겉에 붙은 꼬리표만 달라지고 안의 내용은 그대로입니다. 어떤 프로그램은 파일을 거부하고, 어떤 프로그램은 오류나 빈 화면을 보여 줍니다. 제대로 변환하면 HEIC 사진을 읽어서 진짜 JPEG로 다시 저장하는데, 위 변환기가 바로 이 일을 합니다.

## 변환하면 사진이 달라지나요?

사진 자체는 그대로입니다. 색감, 가로세로 크기, 방향 모두 같습니다. 다만 두 가지는 알아 두세요.

- **파일 용량이 커집니다.** 같은 사진이라도 JPG는 보통 HEIC보다 1.5~2배 큽니다. 사이트에 용량 제한이 있다면 변환한 뒤 [100KB로 줄이기](/resize-image-to-100kb)나 [50KB로 줄이기](/resize-image-to-50kb)를 이용하세요.
- **라이브 포토의 움직임은 빠집니다.** 라이브 포토는 HEIC 사진 한 장과 짧은 영상이 합쳐진 것입니다. 변환하면 정지된 사진 한 장만 남습니다.

## 윈도우나 안드로이드 사용자에게 HEIC 사진 보내는 방법

아이폰에서 보낸다면 다음 방법이 가장 간단합니다.

1. **이메일이나 메신저 앱** – 사진 앱에서 내보낼 때 iOS가 보통 자동으로 JPG로 바꿔 줍니다.
2. **맥으로 에어드롭** – 맥은 HEIC를 그대로 받아도 잘 엽니다.
3. **USB 케이블로 PC에 연결** – *Mac 또는 PC로 전송*을 *자동*으로 해 두면 윈도우에 JPG로 들어갑니다.
4. **클라우드 링크**(구글 드라이브, 드롭박스, 원드라이브) – 원본 HEIC 그대로 전달되므로 받는 사람이 변환해야 할 수 있습니다. 그럴 땐 [HEIC JPG 변환기](/heic-to-jpg) 링크를 함께 보내 주세요. 상대방 휴대폰에서도 쓸 수 있습니다.
