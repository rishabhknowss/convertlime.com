Invoice怎么写？在顶部写上你和客户的信息，加一个唯一的发票编号、开票日期和付款期限，逐行列出产品或服务的数量和单价，最后算出税费和应付总额。最快的办法是用一个免费工具，比如ConvertLime的[发票生成器](/invoice-generator)：选个模板，直接在发票上填写，几分钟就能下载一份PDF，不用注册。这篇教程会讲清楚一张Invoice要写哪些内容，以及怎么一步步做出来。

先说明一点：这里说的Invoice是商业发票，也就是开给客户的账单或请款单，常用于自由职业接单、给海外客户收款和跨境贸易，报价阶段也可以做成形式发票（Proforma Invoice）。它不是国内税务系统开具的增值税发票，不能用来报销或抵扣税款。

## 一张Invoice要写哪些内容

每张Invoice都应该包含下面这些部分。漏掉其中一项，是发票被拖延付款最常见的原因。

| 部分 | 写什么 | 为什么重要 |
| --- | --- | --- |
| 开票方信息 | 公司名称或姓名、地址、邮箱、电话 | 让客户知道该付钱给谁 |
| 收票方信息 | 客户名称或公司、地址 | 写明是谁欠这笔钱 |
| 发票编号 | 唯一的编号，比如INV-0001 | 方便你和客户对账、存档 |
| 开票日期 | 发出发票的那一天 | 付款周期从这天开始算 |
| 付款期限 | 具体的付款截止日期 | 避免在时间上产生误会 |
| 项目明细 | 每个产品或服务、数量、单价 | 说明客户在为什么付钱 |
| 合计 | 小计、折扣、税费、应付总额 | 清楚算出要付的金额 |
| 收款信息 | 银行账户、付款链接或付款方式 | 让客户付款更方便 |

有些国家和地区还有额外要求，比如写上你的VAT或GST税号，企业间交易还要写客户的税号。如果你做过税务登记，就把税号写在开票方信息下面。给海外客户开票时，币种通常用USD，金额一栏要写清楚币种，避免对方误以为是人民币。

## 发票编号怎么编

每张发票都需要一个唯一、按顺序递增的编号。这样你能清楚地追踪谁付了款、谁还没付，很多税务机关也会要求连续编号。格式越简单越好：

- **INV-0001、INV-0002、INV-0003**：前缀加流水号。
- **2026-001、2026-002**：年份加流水号，每年从头开始。
- **ACME-014**：客户代码加流水号，适合固定给几个客户频繁开票的情况。

## Invoice上的税费怎么算

税费是按折扣后的小计来计算的。举个例子：两天的设计工作，每天¥3,000，合计¥6,000。打九折后小计变成¥5,400，再加6%的税费¥324，应付总额就是¥5,724。

如果是给海外客户开的USD发票，算法也一样：两天工作每天$400，共$800；打九折后小计$720，加20%的VAT $144，应付总额$864。

在发票上要写明税率，而不只是税额，方便客户核对。如果你没有做税务登记、不需要收税，把税率留为0就行。
