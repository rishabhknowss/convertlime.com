HEIC是什么格式？它是用 **高效图像容器（High Efficiency Image Container）** 格式保存的照片。从iOS 11开始，iPhone和iPad默认都用这种格式拍照，所以如果一张照片来自iPhone、结尾是`.heic`，原因就在这里。HEIC照片和JPG看起来一样清楚，大小却只有一半左右，问题是Windows、很多网站和老软件都打不开它。

最快的解决办法，就是把照片转成到哪儿都能打开的JPG。下面会讲清楚HEIC是怎么来的、为什么打不开，以及几种简单的处理办法。

## iPhone为什么用HEIC格式？

苹果改用HEIC是为了节省存储空间。一张普通的1200万像素iPhone照片，存成HEIC大约1.5到2MB，存成JPG则是3到4MB，而且看不出任何区别。HEIC还能在一个文件里保存好几张图片，实况照片和连拍就是这样实现的。

## 为什么我的HEIC文件打不开？

HEIC使用的是HEVC（H.265）编码，这种技术需要专利授权，所以各处的支持程度参差不齐：

| 在哪里打开 | 能打开HEIC吗？ |
| --- | --- |
| iPhone、iPad、Mac（“照片”、预览） | 能 |
| Windows 10 / 11 的“照片”应用 | 只有装了付费的HEVC扩展才能 |
| Chrome、Edge、Firefox | 不能 |
| Google相册、Dropbox | 能，可以显示预览 |
| 求职、签证和考试报名的上传页面 | 通常会被拒 |
| Word、PowerPoint、旧版Photoshop | 常常不能 |

## 不转换也能打开HEIC文件的方法

- **Windows：** 从Microsoft Store安装 *HEVC视频扩展*（约0.99美元），之后“照片”应用就能打开HEIC。
- **Mac：** 双击文件即可，预览本身就能打开。
- **安卓：** Google相册和大多数较新的相册App都能显示HEIC。

如果你只是要发送或上传照片，直接转换比安装东西更快，也不用花钱。

## 怎样让iPhone不再拍HEIC格式的照片

1. 打开 **设置**。
2. 点 **相机**，再点 **格式**。
3. 选择 **兼容性最佳**。

之后拍的照片都会存成JPG。另外，当你用邮件发送照片，或者用隔空投送发给非苹果设备时，iPhone也会自动把HEIC转成JPG。用数据线传到电脑时，可以把 **设置 → 照片 → 传输到Mac或PC** 设为 **自动**。

## 能不能直接把.heic改名成.jpg？

不能。改名只是换了个标签，里面的数据并没有变。有些软件会拒收这个文件，有些会报错或显示一片空白。真正的转换会先解开HEIC照片，再重新存成一张标准的JPEG，上面的转换工具做的正是这件事。转换后的照片，任何电脑、手机和网站都能正常打开。

## 转换会改变我的照片吗？

画面本身不会变：颜色一样、像素尺寸一样、方向也一样。不过有两点值得知道：

- **文件会变大。** 同一张照片，JPG通常是HEIC的1.5到2倍大。如果表格有大小限制，转换后可以[把JPG压缩到100KB](/resize-image-to-100kb)或[50KB](/resize-image-to-50kb)。
- **实况照片的动态效果会去掉。** 实况照片是一张静态HEIC加一段短视频，转换后保留的是那张静态画面。

## 怎样把HEIC照片发给用Windows或安卓的人

如果是从iPhone分享，最简单的办法有这些：

1. **邮件或聊天App**：照片离开“照片”App时，iOS通常会自动把它转成JPG。
2. **隔空投送到Mac**：Mac会保留HEIC，而且能正常打开。
3. **用USB数据线传到电脑**：把 *传输到Mac或PC* 设为 *自动*，Windows收到的就是JPG。
4. **云盘链接**（Google云端硬盘、Dropbox、OneDrive）：这些会保留原始的HEIC，所以对方可能需要自己转换。把[HEIC转JPG工具](/heic-to-jpg)的链接发给对方就行，在手机上也能用。
