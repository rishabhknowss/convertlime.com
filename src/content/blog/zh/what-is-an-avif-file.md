AVIF是什么格式？它是用 **AV1图像文件格式（AV1 Image File Format）** 保存的图片，这是一种较新的图片格式，目标是让网页图片尽可能小，同时保持清晰。如果你从网站上保存了一张图片，结尾是`.avif`，那是网站为了让页面加载更快而选用了这种格式。麻烦在于：有些软件、老电脑和很多上传页面仍然打不开AVIF文件，所以最简单的办法就是把图片转成JPG。

## AVIF文件从哪里来

你几乎不会自己制作AVIF文件。它们通常是这样来到你手里的：

- **从网站保存图片。** 购物网站、新闻网站和博客经常给新版浏览器发送AVIF图片。
- **从图片网站或图库下载，** 这些网站会把AVIF作为更小的下载选项。
- **部分手机和相机** 根据设置不同，可能会把照片存成AVIF或相关的HEIF系列格式。
- **别人发给你的文件，** 而对方是从网上保存的图片。

这种格式由开放媒体联盟（Alliance for Open Media）制定，也就是推出AV1视频格式的那一群科技公司。名字就是这么来的：AVIF把AV1用于视频的压缩方式，用在了单张静态图片上。

## AVIF文件为什么这么小

AVIF能用很少的空间装下很多画面细节。和JPG相比，在文件很小的时候，它能让天空、肤色和渐变保持平滑干净，而JPG这时候已经开始出现方块了。它还支持JPG做不到的事：

- **透明背景**，和PNG一样。
- **更丰富的色彩**，在支持的屏幕上还能显示HDR。
- **动画**，有点像GIF，但小得多。

对网站来说，图片越小，网页越快。对你来说，却意味着有些软件还不知道怎么打开这个文件。

## AVIF格式在哪些地方能打开？

支持的地方越来越多，但还不够普及。大致情况如下：

| 较新iPhone、iPad和Mac上的Safari | 能 |
| Windows 11的“照片”应用 | 通常能，有时需要免费的AV1扩展 |
| 较老的Windows软件和看图工具 | 常常不能 |

| 冲印店和自助照片打印机 | 经常被拒 |

如果你要用图片的地方在表格靠下的位置，就先转换。

## 打开或转换AVIF的其他方法

不一定非要用转换工具。下面是系统自带的几种办法，各有利弊：

- **用浏览器打开。** 把AVIF文件拖进Chrome、Edge、Firefox或Safari窗口，就能显示出来。看一看没问题，但文件本身并没有改变。
- **Windows“照片”应用。** 在Windows 11上双击文件。如果打不开，从Microsoft Store安装免费的 *AV1视频扩展* 后再试。

- **截图。** 应急时可以用，但会损失画质，图片大小也会变成屏幕能显示的尺寸。这只是最后的办法，不算真正的转换。

| 透明背景 | 支持 | 支持 | 不支持 |
