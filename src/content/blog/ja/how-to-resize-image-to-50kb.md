画像を50KBに圧縮するには、無料の[画像を50KBに縮小](/resize-image-to-50kb)ツールを開き、写真を入れて、できあがったJPGをダウンロードするだけです。ファイルが50KBを少し下回るまで画質を少しずつ下げ、画質だけでは足りないときにだけ幅と高さを小さくします。顔写真やサインのほとんどは、50KBあれば十分くっきり見えます。

うまく仕上げるコツは、フォームが求めている**KB**と**ピクセル**という2つの違うものを理解し、写真とサインを少し違う方法で扱うことです。

オンライン申請、資格試験の申し込み、採用の応募フォーム、Webで提出する履歴書の写真など、さまざまな場面で役立ちます。

## KBとピクセルの違い: フォームが本当に求めているもの

写真を「小さく」したのに、フォームではじかれてしまう方はたくさんいます。たいていは、変えるべきものを間違えているのが原因です。

| | ピクセル | KB |
| --- | --- | --- |
| 何を表す？ | 写真の幅×高さ | ファイルが使う容量 |
| 例 | 600×800 | 48KB |
| 確認方法 | 写真の情報やファイルのプロパティ | ファイルのプロパティや詳細情報 |
| 何で変わる？ | 切り取り、サイズ変更 | 画質、写っているものの細かさ、ピクセル数 |
| フォームでの書き方の例 | 「縦横200×230ピクセル」 | 「20KB以上50KB以下」 |

フォームでピクセルとKBの**両方**を指定されている場合は、先にピクセル数を合わせて（切り取るかサイズを変えて）から、ファイルを50KBにします。逆の順番にすると、またファイルが上限を超えてしまうことがあります。

## 画像を50KBに圧縮する手順

1. 顔と肩の上のあたりが写真の大部分を占めるように切り取ります。サインなら、インクのすぐ近くで切り取ります。
2. スマホかパソコンで[画像を50KBに縮小](/resize-image-to-50kb)ツールを開きます。
3. 写真を枠の中にドラッグするか、タップして選びます。JPG、PNG、WebP、iPhoneのHEICの写真に対応しています。
4. 1秒ほど待ちます。ツールはブラウザの中で動くので、写真がどこかに送られることはありません。
5. **ダウンロード**をクリックしてJPGを保存します。

フォームでもう少し大きなサイズが使えるなら、上限が大きいほどきれいに見えます。[100KB](/resize-image-to-100kb)を試してみましょう。もっと小さいサイズを求められた場合は、[20KBのツール](/resize-image-to-20kb)を使います。

## 写真とサインでは気をつけることが違う

### 写真: 顔を大きく写す

顔写真には、肌、髪、目、背景が写っていて、そのすべてが容量を使います。50KBあれば細かいところまできれいに残せますが、それは顔が写真いっぱいに写っている場合だけです。全身の写真を50KBまで小さくすると、顔が小さくぼやけてしまいます。

- サイズを変える前に、頭と肩のあたりで切り取ります。
- 後ろの天井の照明ではなく、正面からの自然な光で撮ります。
- 背景には無地の壁を使います。ごちゃごちゃした背景は、顔に使いたい容量を消費してしまいます。
- チャットアプリで保存した写真ではなく、カメラで撮った写真から始めます。

### サイン: 線を濃くはっきりさせる

サインは白地に濃い線があるだけのシンプルなものなので、とても簡単に50KB以下に収まります。よくあるつまずきは、サイズではなく撮り方にあります。

- 白い無地の紙（罫線なし）に、黒か濃い青のペンでサインします。
- 影ができないように、明るい場所で真上からまっすぐ撮ります。
- テーブルや指、紙の余った部分は切り取ります。

## 顔をくっきり残すために本当に役立つこと

| こうしましょう | これは避けましょう |
| --- | --- |
| サイズを変える前にしっかり切り取る | 全身の写真をそのまま小さくする |
| カメラで撮った元の写真を使う | LINEで届いた写真やスクリーンショットを使う |
| 最終的な上限に向けて1回で縮小する | 何度も縮小をくり返す |
| 顔に均一に光を当てる | 強い影や逆光 |
| 無地の背景 | 柄のあるカーテンや散らかった部屋 |

JPGを低い画質で保存するたびに、細かい部分が少しずつ失われます。だからこそ、元の写真から1回で50KBにするのがいちばんです。

## 写真を50KB以下にするほかの方法

**Windows:** **ペイント**で**サイズ変更**を選び、**ピクセル**に切り替えて小さな幅を入力し、JPEGで保存します。右クリック →**プロパティ**でサイズを確認します。まだ大きすぎれば、もう一度くり返します。

**Mac:** **プレビュー**で**ファイル → 書き出す**を選び、**JPEG**にして、**品質**のスライダーを左に動かします。スライダーの下にファイルサイズが表示されるので、50KBを下回ったところで止めましょう。

**スマホ:** KB単位でサイズを選べる機能は最初から入っていないので、ブラウザのツールを使うのがいちばん簡単です。画質を自分で選びたい場合は、[画像圧縮](/compress-image)ツールにスライダーがあり、上限のサイズもKBで指定できます。

## それでもアップロードできないときは

- **大きすぎる:** 元の写真ではなく、新しいファイルをアップロードしたか確認しましょう。ダウンロードしたファイルは、ふつう「ダウンロード」フォルダーに入っています。
- **小さすぎる:** 下限があるフォームもあります。より大きくはっきりした写真から始めるか、[画像圧縮ツール](/compress-image)で画質を高めにしましょう。
- **形式が違う:** フォームはJPGを求めています。50KBのツールで作ったファイルは必ずJPGです。
- **大きさ（ピクセル数）が違う:** 案内で指定されたピクセル数ぴったりに切り取ってから、もう一度50KBに縮小しましょう。

資格試験やオンライン申請で、さらに小さなサイズを指定されていませんか？ [画像を20KBにする方法](/blog/how-to-resize-image-to-20kb)のガイドで、申し込みフォーム向けのポイントをくわしく説明しています。サイズの上限は申し込み先によって違うので、必ずご自分のフォームの案内を確認してください。
