AVIFファイルとは、**AV1 Image File Format**という形式で保存された画像のことです。ウェブの画像をくっきりした見た目のまま、できるだけ小さくするために作られた新しい形式です。ウェブサイトから保存した画像の末尾が `.avif` になっていたら、それはページを速く表示するために、サイトがこの形式を選んでいるからです。困るのは、一部のアプリや古いパソコン、多くのアップロードフォームでは、まだAVIFファイルを開けないことです。いちばん簡単な解決方法は、画像をJPGに変換することです。

## AVIFファイルはどこから来る？

ご自分でAVIFを作ることは、まずありません。たいていは次のような形で手元に届きます。

- **ウェブサイトから画像を保存したとき。** ネットショップ、ニュースサイト、ブログは、新しいブラウザにAVIF画像を送っていることがよくあります。
- **画像サイトや素材サイトからのダウンロード。** 小さいファイルの選択肢としてAVIFを用意しているサイトがあります。
- **一部のスマホやカメラ。** 設定によっては、AVIFや、その仲間のHEIF形式で写真を保存できます。
- **人から送られてきたファイル。** ウェブから画像を保存した人が送ってくることがあります。

この形式は、AV1という動画形式を作ったIT企業のグループ、Alliance for Open Mediaによって作られました。名前の由来もそこにあります。AVIFは、AV1が動画に使っているのと同じ圧縮方法を、1枚の静止画に使っているのです。

## AVIFファイルがとても小さい理由

AVIFは、ごくわずかなデータに写真をたっぷり詰め込めます。JPGと比べると、ファイルを小さくしても、なめらかな空や肌の色、グラデーションがきれいなまま残ります。JPGなら、そこまで小さくするとカクカクしてくるところです。さらに、JPGにはできないことにも対応しています。

- PNGのような**透明な背景**
- 対応する画面でのHDRを含む、**より豊かな色**
- GIFに少し似ているけれど、ずっと小さい**アニメーション**

ウェブサイトにとっては、画像が小さいほどページが速く表示されます。一方、使う側にとっては、まだ開き方を知らないソフトもあるファイルということになります。

## AVIFファイルはどこで開ける？

対応している場所はずいぶん増えましたが、まだばらつきがあります。おおまかには次のとおりです。

| 開く場所 | AVIFを開ける？ |
| --- | --- |
| Chrome、Edge、Firefox（最新版） | 開ける |
| 最近のiPhone、iPad、MacのSafari | 開ける |
| Windows 11のフォトアプリ | たいてい開ける（無料のAV1拡張機能が必要なことも） |
| 古いWindowsのソフトや画像ビューア | 開けないことが多い |
| Word、PowerPoint、古い写真編集ソフト | 開けないことが多い |
| 求人、ビザ、試験、役所などのアップロードフォーム | たいてい受け付けられない |
| 写真店やプリント機 | 受け付けられないことが多い |

画像を使いたい場所が表の下のほうなら、変換しておきましょう。

## AVIFファイルをJPGに変換する方法

無料でいちばん早いのは、ブラウザの中でそのまま変換する方法です。

1. 無料の[AVIF→JPG変換](/avif-to-jpg)を開きます。
2. AVIF画像を枠の中にドラッグするか、枠をタップしてファイルから選びます。
3. 画像は、お使いの機器の中ですぐに変換されます。アップロードされることはありません。
4. **ダウンロード**をクリックします。何枚か追加した場合は、まとめてZIPでダウンロードできます。

新しいJPGは、どのパソコン、スマホ、ウェブサイトでも開けます。透明な背景を残したい画像なら、JPGは透明な部分を保存できないので、代わりに[AVIF→PNG変換](/avif-to-png)を使いましょう。小さいまま、最近のほとんどのウェブサイトで使えるものがほしい場合は、[AVIF→WebP変換](/avif-to-webp)という方法もあります。

## AVIFを開いたり変換したりするほかの方法

変換ツールがいつも必要なわけではありません。最初から使える方法と、それぞれの注意点を紹介します。

- **ブラウザで開く。** AVIFファイルをChrome、Edge、Firefox、Safariのウィンドウにドラッグすると表示されます。見るだけならこれで十分ですが、ファイルそのものは変わりません。
- **Windowsのフォト。** Windows 11では、ファイルをダブルクリックします。開かない場合は、Microsoft Storeから無料の*AV1 Video Extension*をインストールして、もう一度試してください。
- **Macのプレビュー。** 最近のmacOSでは、プレビューでAVIFを開けます。そこから**ファイル → 書き出す**でJPEGを選び、コピーを保存できます。
- **スクリーンショットを撮る。** とりあえずの手段にはなりますが、画質が落ち、画像の大きさも画面に収まるサイズに変わってしまいます。本当の変換ではなく、最後の手段です。

どれも面倒に感じたら、上の変換ツールを使えば、数秒で元の大きさのままのきちんとしたJPGが手に入ります。

## AVIF・WebP・JPGの比較

この3つはどれもウェブサイトで見かけるので、よく混同されます。

| | AVIF | WebP | JPG |
| --- | --- | --- | --- |
| ファイルサイズ | いちばん小さい | 小さい | 3つの中でいちばん大きい |
| 透明な背景 | 対応 | 対応 | 非対応 |
| アニメーション | 対応 | 対応 | 非対応 |
| 古いパソコンやアプリで開ける | 開けないことが多い | 開けないこともある | 開ける |
| アップロードフォームで使える | ほとんど使えない | 使えることもある | ほぼ必ず使える |

どれが必要かわからなければ、JPGを選びましょう。どこでもそのまま使える形式です。真ん中のWebPについては、[WebPファイルとは？](/blog/what-is-a-webp-file)のガイドでくわしく説明しています。

## AVIFファイルを開いても安全？

AVIFファイルは、JPGやPNGと同じただの画像です。いつもと同じように気をつけて、信頼できる人やウェブサイトからのファイルだけを開き、ブラウザやパソコンを最新の状態にしておきましょう。ConvertLimeで変換する場合、画像はブラウザの中で扱われ、どこにも送られません。

## 変換したあと: JPGを小さくするには

AVIFから作ったJPGは、ふつう元のファイルより大きくなります。JPGはAVIFほど効率よく小さくできない形式だからです。ウェブサイトでファイルが大きすぎると言われたら、次の方法を試してください。

- [画像圧縮ツール](/compress-image)で、くっきりした見た目のまま小さくする
- フォームで決まった上限を指定されている場合は、[100KBに縮小](/resize-image-to-100kb)する

## まとめ

AVIFファイルは、主にウェブサイトで使われている、新しくてとても小さな画像形式です。ブラウザでは問題なく開けますが、多くのアプリや古いパソコン、アップロードフォームでは使えません。どこでも使える画像が必要なときは、登録不要・アップロードなしで、無料で[AVIFをJPGに変換](/avif-to-jpg)しましょう。
