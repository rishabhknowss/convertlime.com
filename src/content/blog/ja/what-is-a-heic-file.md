HEICファイルとは、**High Efficiency Image Container（高効率画像コンテナ）**という形式で保存された写真のことです。iOS 11以降、iPhoneとiPadの標準の保存形式になっているため、iPhoneで撮った写真の末尾が `.heic` になっているのはそのためです。HEICの写真はJPGと同じくらいきれいなのに、サイズはおよそ半分。ただし、Windowsや多くのウェブサイト、古いアプリでは開けないことがあります。

いちばん手早い解決方法は、どこでも開けるJPGに変換することです。

<!-- cta -->

## iPhoneがHEICファイルを使う理由

Appleが写真の保存形式をHEICに切り替えたのは、本体の容量を節約するためです。一般的な1200万画素のiPhoneの写真は、HEICなら約1.5〜2MB、JPGなら約3〜4MBで、見た目の違いはありません。また、HEICは1つのファイルに複数の画像をまとめられるので、Live Photosや連写もこの仕組みで保存されています。

## HEICファイルが開けないのはなぜ？

HEICはHEVC（H.265）という特許ライセンスが必要な技術を使っています。そのため、対応している場所とそうでない場所がまちまちです。

| 開く場所 | HEICは使える？ |
| --- | --- |
| iPhone、iPad、Mac（写真、プレビュー） | 使える |
| Windows 10 / 11 のフォトアプリ | 有料のHEVC拡張機能があれば使える |
| Chrome、Edge、Firefox | 使えない |
| Googleフォト、Dropbox | 使える（プレビュー表示） |
| 求人・ビザ・試験などの申し込みフォーム | 受け付けられないことが多い |
| Word、PowerPoint、古いPhotoshop | 使えないことが多い |

## HEICファイルをJPGに変換する方法

1. 無料の[HEIC→JPG変換](/heic-to-jpg)を開きます。
2. HEICの写真を枠の中にドラッグするか、枠をタップしてファイルから選びます。
3. 写真は1枚あたり約1秒で、ブラウザの中で変換されます。写真がどこかに送られることはありません。
4. **ダウンロード**をクリックします。複数の写真を追加した場合は**ZIPでまとめてダウンロード**も使えます。

背景を透明にしたい場合や、画質を一切落とさずに残したい場合は[HEIC→PNG変換](/heic-to-png)を使いましょう。複数の写真を1つの書類にまとめて送りたい場合は[HEIC→PDF変換](/heic-to-pdf)が便利です。

## 変換せずにHEICファイルを開く方法

- **Windowsの場合:** Microsoft Storeから「HEVCビデオ拡張機能」（約0.99ドル）をインストールすると、フォトアプリでHEICを開けるようになります。
- **Macの場合:** ファイルをダブルクリックするだけで、プレビューでそのまま開けます。
- **Androidの場合:** Googleフォトや、最近のほとんどのギャラリーアプリでHEICを表示できます。

写真を送ったりアップロードしたりするだけなら、何かをインストールするより変換したほうが早く済みます。

## iPhoneでHEICの写真を撮らないようにする方法

1. **設定**を開きます。
2. **カメラ**をタップし、続けて**フォーマット**をタップします。
3. **互換性優先**を選びます。

これで、新しく撮る写真はJPGで保存されます。また、写真をメールで送ったり、Apple以外の機器にAirDropで送ったりすると、iPhoneが自動でHEICをJPGに変換してくれます。**設定 → 写真 → MacまたはPCに転送**を**自動**にしておきましょう。

## 拡張子を.heicから.jpgに書き換えるだけでもいい？

いいえ、できません。名前を書き換えても変わるのはラベルだけで、中身のデータはHEICのままです。ファイルを受け付けないアプリもあれば、エラーや真っ白な画像が表示されるアプリもあります。きちんと変換すると、HEICの写真を一度読み込んでから正しいJPEGとして保存し直します。上の変換ツールが行っているのはこの処理です。

## 変換すると写真は変わる？

写真そのものは変わりません。色も、ピクセル数で見た大きさも、向きもそのままです。ただし、知っておくと便利な点が2つあります。

- **ファイルサイズが大きくなります。** 同じ写真でもJPGはHEICの約1.5〜2倍の大きさになるのが普通です。フォームにサイズの上限がある場合は、変換したあとに[JPGを100KBに縮小](/resize-image-to-100kb)するか、[50KBに縮小](/resize-image-to-50kb)しましょう。
- **Live Photosの動きはなくなります。** Live Photoは、静止画のHEICと短い動画を組み合わせたものです。変換すると静止画だけが残ります。

## WindowsやAndroidを使っている人にHEICの写真を送る方法

iPhoneから送る場合、いちばん簡単なのは次の方法です。

1. **メールやメッセージアプリ** – 写真アプリから送り出すとき、iOSが自動でJPGに変換してくれることがほとんどです。
2. **MacへのAirDrop** – MacはHEICのまま受け取り、問題なく開けます。
3. **USBケーブルでPCへ** – 「MacまたはPCに転送」を「自動」にしておけば、WindowsにはJPGとして届きます。
4. **クラウドのリンク**（Googleドライブ、Dropbox、OneDrive） – 元のHEICのまま共有されるため、受け取った人が変換しなければならないことがあります。その場合は[HEIC→JPG変換](/heic-to-jpg)のリンクを送ってあげましょう。相手のスマホでも使えます。

## HEICとJPGの違いをひと目で比較

| | HEIC | JPG |
| --- | --- | --- |
| ファイルサイズ | 約半分 | 大きめ |
| 画質 | とてもきれい | 高品質ならとてもきれい |
| 透過 | 対応 | 非対応 |
| どこでも開ける | いいえ | はい |

変換したあとに、サイトからもっと小さいファイルを求められた場合は、[画像圧縮ツール](/compress-image)を使うか、[決まったKBサイズに縮小](/resize-image-to-100kb)しましょう。
