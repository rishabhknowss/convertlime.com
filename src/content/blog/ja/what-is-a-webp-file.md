WebPファイルとは、Googleがウェブサイトの画像を小さく、速く表示できるようにするために作った**WebP**という形式で保存された画像のことです。ネットで画像を右クリックして保存したら `.jpg` ではなく `.webp` になったという場合、それはウェブサイトがWebP版の画像を送ってきたからです。ブラウザなら簡単に開けますが、一部のアプリや古いパソコン、アップロードフォームでは使えないことがあります。手早く解決するには、画像をJPGかPNGに変換しましょう。

## 最近、画像がWebPで保存されることが多い理由

ウェブサイトはできるだけ速く表示されたいもので、ページの中でいちばん重いのはたいてい画像です。WebPを使えば、同じ画像をより小さなファイルで表示できます。そのため、ブラウザが画像を受け取るときに多くのサイトがWebP版を渡し、保存するとそれが「ダウンロード」フォルダーに入るのです。

WebPファイルは、次のような場所でよく見かけます。

- ネットショップや商品の写真
- ニュースサイト、ブログ、レシピサイト
- 画像検索の結果
- 一部のメッセージアプリから保存したスタンプや画像

## WebPファイルとほかの形式との違い

WebPは、ふだんなら2〜3種類の形式が必要なことを1つでこなせます。

- **写真**を、同じくらいの画質のJPGより小さなファイルで保存できます。
- PNGのように、**背景が透明なイラスト**を保存できます。
- GIFのように、**短いアニメーション**を保存できます。たいていGIFより小さくなります。

この柔軟さはウェブサイトにはとても便利です。ただ、ふだん使うぶんにはわかりにくいこともあります。`.webp` という末尾だけでは、そのファイルが写真なのか、ロゴなのか、アニメーションなのかがわからないからです。

## WebPファイルはどこで開ける？

| 開く場所 | WebPを開ける？ |
| --- | --- |
| Chrome、Edge、Firefox、Safari | 開ける |
| Windows 11のフォトとペイント | 最新の状態のほとんどのパソコンで開ける |
| 最近のMacのプレビュー | 開ける |
| iPhoneやAndroidの写真アプリ | たいてい開ける |
| 古い写真編集ソフトや画像ビューア | 開けないことが多い |
| Word、PowerPoint、一部のメールソフト | 開けないこともある |
| 求人、ビザ、試験、役所などのアップロードフォーム | 受け付けられないことが多い |
| 写真店やプリント機 | 受け付けられないことが多い |

画像を表の下のほうの場所で使う予定なら、先に変換しておきましょう。

## WebPファイルを変換する方法

1. 無料の[WebP→JPG変換](/webp-to-jpg)を開きます。
2. WebP画像を枠の中にドラッグするか、枠をタップして選びます。
3. 画像はブラウザの中で、すぐに変換されます。アップロードされることはありません。
4. **ダウンロード**をクリックします。何枚か追加した場合は、まとめてZIPでダウンロードできます。

用途に合った形式を選ぶことが大切です。

- **共有、アップロード、印刷したい写真なら:** [WebP→JPG変換](/webp-to-jpg)
- **ロゴ、スクリーンショット、透けた背景のある画像なら:** [WebP→PNG変換](/webp-to-png)。くわしい手順は[WebPをPNGに変換する方法](/blog/how-to-convert-webp-to-png)のガイドで説明しています。
- **動く画像なら:** [WebP→GIF変換](/webp-to-gif)
- **書類が必要なら:** [WebP→PDF変換](/webp-to-pdf)

ネットで見つけた画像のJPGのコピーがほしいだけなら、WindowsやMacに最初から入っている機能も含めて、[WebPをJPGで保存する方法](/blog/how-to-save-webp-as-jpg)ですべての方法を紹介しています。

## WebP・JPG・PNGの比較

| | WebP | JPG | PNG |
| --- | --- | --- | --- |
| 向いている用途 | ウェブページ | 写真 | ロゴ、文字、スクリーンショット |
| ファイルサイズ | 小さい | 中くらい | 大きい |
| 透明な背景 | 対応 | 非対応 | 対応 |
| アニメーション | 対応 | 非対応 | 非対応 |
| どこでも開ける | そうとは限らない | 開ける | 開ける |

まとめると、ウェブサイトにはWebPがいちばん向いていて、それ以外のほとんどの用途にはJPGかPNGが向いています。

## 変換せずにWebPファイルを開く方法

画像を見たいだけなら、変換する必要はないかもしれません。

- **どのパソコンでも:** ファイルをChrome、Edge、Firefox、Safariのウィンドウにドラッグします。
- **Windows 11:** ダブルクリックします。最新の状態のほとんどのパソコンでは、フォトアプリでWebPを開けます。
- **Mac:** ダブルクリックすると、プレビューで開きます。
- **スマホ:** ファイルアプリやダウンロードのアプリから開きます。ほとんどのギャラリーアプリで表示できます。

変換が必要になるのは、WebPを受け付けない場所に画像をアップロードしたり、印刷したり、編集したり、送ったりするときだけです。

## .webpを.jpgに名前変更するだけでもいい？

いいえ。名前を変えても、変わるのはラベルだけです。中の画像はWebPのままなので、エラーが出たりファイルを受け付けなかったりするアプリもありますし、中身を確認するアップロードフォームでははじかれます。きちんと変換すると、WebP画像を開いてから正しいJPGとして保存し直します。

## 逆に、自分でWebPファイルを作るには

ウェブサイトやネットショップを運営しているなら、WebPを使うとページを速く表示できます。手元の画像は、[JPG→WebP変換](/jpg-to-webp)や[PNG→WebP変換](/png-to-webp)でWebPにできます。WebPを受け付けない場所で必要になるときのために、元のJPGやPNGも残しておきましょう。

## まとめ

WebPファイルは、ウェブサイト向けに作られた、小さくて新しい画像です。ブラウザでは問題なく開けますが、ほかの場所ではそうとは限りません。どのアプリでもどのフォームでも使える画像が必要なときは、登録不要・アップロードなしで、無料で[WebPをJPGに変換](/webp-to-jpg)するか、PNGに変換しましょう。
