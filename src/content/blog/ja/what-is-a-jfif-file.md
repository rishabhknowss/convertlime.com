JFIFファイルとは、末尾が `.jpg` ではなく `.jfif` になっているだけの、ふつうのJPEG画像のことです。JFIFは**JPEG File Interchange Format**の略で、JPEG画像を保存するときの標準的な決まりにすぎません。中の画像はほかのJPGと同じで、保存するときにWindowsが別の名前をつけただけです。そのため、JFIFファイルはパソコンでは問題なく開けるのに、`.jpg` や `.jpeg` しか受け付けないアップロードフォームでははじかれてしまうことがあります。

## 画像が.jfifで保存されてしまう原因

これはたいてい、Windowsでウェブブラウザの画像を右クリックして保存したときに起こります。Windowsは、ファイルの種類ごとにどの拡張子を使うかの一覧を持っています。パソコンによっては、ほかのソフトが書き換えたことなどが原因で、この一覧でJPEG画像の拡張子が `.jpg` ではなく `.jfif` になっていることがあります。ブラウザはこの設定に従うので、ダウンロードした画像の末尾が `.jfif` になるのです。

画像そのものには何の問題もありません。同じ画像で、画質もピクセル数も同じです。

## JFIFファイルとJPG・JPEGの違い

| | .jfif | .jpg | .jpeg |
| --- | --- | --- | --- |
| 画像の種類 | JPEG | JPEG | JPEG |
| 画質 | 同じ | 同じ | 同じ |
| ブラウザや写真アプリで開ける | はい | はい | はい |
| アップロードフォームで使える | 使えないことも | はい | はい |
| よく見かける場面 | Windowsでのダウンロード | カメラ、スマホ、ウェブサイト | 一部のカメラやアプリ |

`.jpg` と `.jpeg` はまったく同じように使えます。この2つを切り替えたい場合は、[JPG→JPEG変換](/jpg-to-jpeg)や[JPEG→JPG変換](/jpeg-to-jpg)を使いましょう。

## JFIFファイルをJPGにする3つの方法

いちばん簡単だと思う方法を選んでください。どれを使っても、ふつうのJPGになります。

### 方法1: オンラインで無料で変換する

ウェブサイトで何度もはじかれる場合や、画像がたくさんある場合は、これがいちばん確実です。

1. 無料の[JFIF→JPG変換](/jfif-to-jpg)を開きます。
2. JFIFの画像を枠の中にドラッグするか、枠をタップして選びます。
3. ブラウザの中で、1枚ずつ正しいJPGとして保存されます。アップロードされることはありません。
4. **ダウンロード**をクリックするか、まとめてZIPでダウンロードします。

### 方法2: ファイルの名前を変える

JFIFファイルの中身はすでにJPEG画像なので、名前を変えるだけでたいていうまくいきます。

1. Windowsでエクスプローラーを開き、**表示**メニューから**ファイル名拡張子**をオンにして、末尾の `.jfif` が見えるようにします。
2. ファイルを右クリックして**名前の変更**を選びます。
3. `.jfif` を `.jpg` に書き換えて、**Enter**キーを押します。
4. 拡張子を変えることについてWindowsから確認されたら、**はい**をクリックします。

Macでは、Finderでファイル名をクリックして末尾を `.jpg` に書き換え、**".jpg"を使用**をクリックして確定します。

### 方法3: ペイントやプレビューでコピーを保存する

- **Windows:** ファイルをペイントで開き、**ファイル → 名前を付けて保存 → JPEG画像**を選んで保存します。
- **Mac:** ファイルをプレビューで開き、**ファイル → 書き出す**を選んで、フォーマットを**JPEG**にして保存します。

この方法では画像を保存し直します。1〜2枚なら問題ありませんが、フォルダーごと処理するには時間がかかります。

## Windowsで画像がJFIFで保存されないようにする方法

原因は、Windowsのレジストリにある設定ひとつです。レジストリを間違って編集すると不具合が起きることがあるので、慣れている方だけ変更してください。自信がない場合は、届いたファイルをそのつど名前変更するか変換しましょう。

1. **Windows + R**キーを押し、`regedit` と入力して**Enter**キーを押します。
2. `HKEY_CLASSES_ROOT\MIME\Database\Content Type\image/jpeg` に移動します。
3. 右側にある**Extension**という名前の値をダブルクリックします。
4. `.jfif` を `.jpg` に変えて、**OK**をクリックします。
5. レジストリ エディターを閉じて、ブラウザを開き直します。

これで、新しくダウンロードした画像は `.jpg` で保存されるはずです。すでに保存したファイルは `.jfif` のままなので、名前を変えるか変換しましょう。

## PNGやPDFが必要な場合は？

フォームによっては、JPG以外を求められることもあります。

- **PNGが必要なら:** [JFIF→PNG変換](/jfif-to-png)を使いましょう。JPEG画像から作ったPNGはサイズが大きくなり、背景が透明になるわけでもない点に注意してください。
- **書類が必要なら:** [JFIF→PDF変換](/jfif-to-pdf)で、1枚または複数の画像を1つのPDFファイルにまとめられます。
- **ファイルが大きすぎるなら:** 変換したあとにJPGを[画像圧縮ツール](/compress-image)にかけるか、フォームで上限が決まっている場合は[200KBに縮小](/resize-image-to-200kb)しましょう。

## JFIFファイルは安全？

JFIFファイルは、JPGと同じただの画像です。この拡張子自体は危険のサインではなく、Windowsの設定が表れているだけです。どんなファイルでも同じですが、信頼できる人やウェブサイトからの画像だけを開くようにしましょう。

## まとめ

JFIFファイルは、珍しい拡張子がついたJPEG画像です。名前を `.jpg` に変えるか、ペイントやプレビューでコピーを保存するか、無料の[JFIF→JPG変換](/jfif-to-jpg)を使えば、数秒できれいなJPGにできます。ほかにも見慣れない拡張子に出会ったら、[AVIFファイル](/blog/what-is-an-avif-file)や[HEICファイル](/blog/what-is-a-heic-file)のガイドもご覧ください。
