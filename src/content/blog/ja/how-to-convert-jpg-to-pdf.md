JPGをPDFに変換するには、ConvertLimeの[JPG→PDF変換](/jpg-to-pdf)のような無料ツールを開き、写真を追加してページサイズを選び、PDFをダウンロードするだけです。どの機器でもこれがいちばん早い方法です。パソコンやスマホに最初から入っている機能でもできます。Windowsなら**Microsoft Print to PDF**、Macなら**プレビュー**、iPhoneなら**ファイル**アプリや**プリント**の機能です。このガイドでは、それぞれの方法でJPGをPDFにする手順を順番に紹介します。

## ConvertLimeでJPGをPDFに変換する方法（どの機器でも）

1. ブラウザで[JPG→PDF変換](/jpg-to-pdf)を開きます。
2. JPGファイルを枠の中にドラッグするか、タップして選びます。ページを並べたい順番で追加しましょう。
3. ページサイズを選びます。
   - **画像と同じ** – どのページも写真とまったく同じ形になり、白いふちができません。
   - **A4** – 一般的な用紙のサイズで、印刷や役所などの書類に向いています。
4. **ダウンロード**をクリックします。1つのPDFの中で、写真が1枚ずつ別のページに入っています。

ファイルは最初から最後まで、お使いの機器の中にあります。PNGファイルなら[PNG→PDF変換](/png-to-pdf)を、いろいろな形式が混ざっているときは[画像→PDF変換](/image-to-pdf)を使いましょう。

## WindowsでJPGをPDFに変換する方法

Windows 10と11には、紙ではなくPDFファイルに保存する**Microsoft Print to PDF**という「プリンター」が最初から入っています。

1. **エクスプローラー**を開き、JPGファイルを探します。1枚選ぶか、**Ctrl**キーを押しながらクリックして複数選びます。
2. 右クリックして**印刷**を選びます。Windows 11では、先に**その他のオプションを確認**をクリックする必要があるかもしれません。
3. **画像の印刷**の画面で、プリンターを**Microsoft Print to PDF**にします。
4. 用紙サイズと、右側のレイアウト（たとえば**フルページ写真**）を選びます。
5. 写真のはしが切れてほしくない場合は、**写真をフレームに合わせる**のチェックを外します。
6. **印刷**をクリックし、保存先を選んで名前を入力し、**保存**をクリックします。

写真を1枚だけ**フォト**アプリで開き、**Ctrl + P**を押して、プリンターにMicrosoft Print to PDFを選ぶ方法もあります。

## MacでJPGをPDFに変換する方法

**写真が1枚の場合:**

1. JPGをダブルクリックして**プレビュー**で開きます。
2. **ファイル → PDFとして書き出す**をクリックします。
3. 名前と保存先を決めて、**保存**をクリックします。

**複数の写真を1つのPDFにする場合:**

1. FinderでJPGをすべて選び、右クリックして**このアプリケーションで開く → プレビュー**を選びます。
2. 左側のサイドバーで、写真を並べたい順番にドラッグします。
3. **ファイル → プリント**をクリックします。
4. 左下の**PDF**メニューを開き、**PDFとして保存**を選びます。

## iPhoneでJPGをPDFに変換する方法

最初から入っている機能でいちばん簡単なのは、**ファイル**アプリを使う方法です。

1. **写真**アプリで写真を選び、**共有**をタップして**"ファイル"に保存**を選びます。
2. **ファイル**アプリを開き、保存したフォルダーに移動します。
3. **選択**（または**その他**ボタン→**選択**）をタップし、写真を選びます。
4. 右下の**その他**ボタン（点が3つ）をタップし、**PDFを作成**を選びます。

同じフォルダーに新しいPDFができます。iPhoneの写真はJPGではなくHEICで保存されていることがよくあります。ブラウザでそのままPDFにしたい場合は、[HEIC→PDF変換](/heic-to-pdf)を使いましょう。違いについては[HEICファイルとは？](/blog/what-is-a-heic-file)のガイドで説明しています。

## AndroidでJPGをPDFに変換する方法

ほとんどのAndroidスマホでは、PDFに印刷できます。

1. **Googleフォト**またはギャラリーアプリで写真を開きます。
2. **その他**メニュー（点が3つ）をタップし、**印刷**を探します。
3. 印刷画面の上のほうで、プリンターとして**PDF形式で保存**を選びます。
4. PDFのダウンロードボタンをタップし、保存先を選びます。

メニューの名前はスマホのメーカーによって違います。印刷が見当たらない場合や、複数の写真を1つのPDFにしたい場合は、AndroidのChromeで[JPG→PDF変換](/jpg-to-pdf)が使えます。

## PDFが大きすぎて送れないときは

スマホの写真から作ったPDFは、数MBになることがあります。メールやフォームではじかれた場合は、先に[画像圧縮ツール](/compress-image)で写真を軽くしてからPDFにしましょう。いちばんいい設定は、[画質を落とさずに画像を圧縮する方法](/blog/how-to-reduce-image-size-without-losing-quality)のガイドで説明しています。
