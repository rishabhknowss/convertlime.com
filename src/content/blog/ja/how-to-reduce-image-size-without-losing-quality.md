画質を落とさないで画像を圧縮するには、写真を中〜高めの画質（75〜85くらい）のJPGで保存し、必要以上に大きな写真なら先に幅と高さを小さくします。こうすると、画面での見た目は同じまま、ファイルは数分の1になることがよくあります。ConvertLimeの無料の[画像圧縮](/compress-image)ツールなら、これをブラウザの中で行えます。写真を入れて画質を決め、見比べてからダウンロードするだけです。

## ファイルが小さくても見た目が変わらない理由

スマホのカメラで撮ったままの写真には、画面で表示できるよりもはるかに多くの情報が入っています。一般的なスマホやノートパソコンの画面では、写真は本来のピクセル数のほんの一部の大きさで表示されています。圧縮では、ふつうの大きさで見たときに目では見分けられない細かな情報を取り除くので、写真の見た目は変わらないままファイルが小さくなります。

画質が落ちるのは、やりすぎたときです。とても低い設定にしたり、同じ写真を何度も圧縮したりすると、目に見えて劣化します。次の手順を使えば、ちょうどいいところで止められます。

## ConvertLimeで画像を圧縮する方法

1. [画像圧縮](/compress-image)ツールを開きます。
2. 写真を枠の中にドラッグするか、タップして選びます。JPG、PNG、WebP、AVIF、iPhoneのHEICの写真に対応しています。
3. **画質**のスライダーを合わせます。まずは**80**くらいから始めましょう。
4. ウェブサイトから上限を指定されている場合は、**上限サイズ（KB）**の欄にその数字を入力すると、それを下回るように調整されます。
5. 新しいサイズとプレビューを確認します。くっきり見えていればダウンロードしましょう。ぼやけて見える場合は、画質を少し上げます。

できあがるのはJPGなので、どのスマホ、パソコン、ウェブサイトでも開けます。

## 画質を落とさずに写真を小さくする5つのコツ

### 1. いちばん低い画質ではなく、ほどよい画質を選ぶ

| 画質の設定 | ファイルサイズ | 見た目 |
| --- | --- | --- |
| 90〜100 | いちばん大きい | 元の写真と同じ |
| 75〜85 | かなり小さい | 画面では同じに見える |
| 60〜70 | 小さい | 小さなプレビューなら十分、少しぼやける |
| 50未満 | いちばん小さい | ふちがカクカクし、細かい部分がにじむ |

ほとんどの写真では、真ん中の段がいちばんバランスのいい設定です。

### 2. とても大きな写真はピクセル数を減らす

写真の幅が4000ピクセルあっても、メールやウェブページで表示されるのが1200ピクセルくらいなら、余ったピクセルは重さになるだけです。先に写真のピクセル数を小さくすると、見た目を変えずにファイルサイズを大きく減らせます。

**Mac**では、写真を**プレビュー**で開き、**ツール → サイズを調整**を選びます。**Windows**では、**ペイント**で開いて**サイズ変更**をクリックし、**ピクセル**を選びます。

### 3. 用途に合った形式を使う

- **写真:** JPGを使いましょう。写真をPNGで保存すると、何の得もないのに数倍の大きさになることがあります。[PNG→JPG変換](/png-to-jpg)で変換できます。
- **スクリーンショット、ロゴ、文字:** PNGなら、くっきりしたふちや平らな色がきれいに残ります。
- **ウェブサイト:** WebPは、同じ見た目でもJPGより小さくなることが多いです。お使いのサイトが対応していれば、[JPG→WebP変換](/jpg-to-webp)を試してみましょう。

### 4. 元の写真から1回だけ圧縮する

JPGを低い画質で保存し直すたびに、細かな部分が少しずつ失われます。LINEなどで送られてきた写真や、SNSからダウンロードした写真ではなく、必ずカメラで撮った元の写真から始めましょう。

### 5. いらない部分を切り取る

何もない空や床、背景も容量を使っています。切り取ればファイルが小さくなり、見せたいものも目立ちます。

## どのくらいのサイズを目指せばいい？

| 写真の使い道 | 目安 |
| --- | --- |
| メールの添付ファイル | 300KB〜1MB |
| ウェブサイトやブログの写真 | 100KB〜300KB |
| ネットショップの商品写真 | 100KB〜300KB |
| 試験、求人、役所の申し込みフォーム | フォームの指定どおり |
| 自宅で印刷する | 元の写真のまま |

上限が決まっている場合は、サイズを指定できるツールのほうが早く済みます。[画像を200KBに縮小](/resize-image-to-200kb)や[画像を100KBに縮小](/resize-image-to-100kb)は、画質を少しずつ下げ、必要なときだけピクセル数を小さくします。フォームの上限がとても小さい場合は、[画像を50KBにする方法](/blog/how-to-resize-image-to-50kb)をご覧ください。

## 画質を台なしにするよくある失敗

- **いきなりいちばん低い設定にする。** まずは80を試しましょう。容量が減るのは、ほとんど100から75のあいだです。
- **スクリーンショットを低い画質のJPGにする。** 文字のまわりにもやもやしたにじみが出ます。スクリーンショットはPNGのままにするか、高い画質にしましょう。
- **小さな写真を大きくする。** ピクセル数を増やしても細かさは戻りません。ファイルが大きくなり、ぼやけるだけです。
- **元の写真に上書きする。** 元の大きさの写真は残しておき、圧縮した写真は別のコピーとして保存しましょう。
