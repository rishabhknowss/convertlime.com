## Quando o PNG é a escolha certa

Imagens WebP podem ser fotos, artes ou animações, então ajuda saber para qual formato converter. O PNG é a melhor opção quando:

- **A imagem tem fundo transparente**, como um logo, uma figurinha ou um produto recortado.
- **Ela tem texto**, como um print de tela, um diagrama, um gráfico ou uma arte para redes sociais.
- **Você vai editar a imagem** e não quer que a qualidade caia a cada vez que salvar.
- **Um programa de design, uma apresentação ou um criador de sites** pede PNG.

Para uma foto comum que você só quer compartilhar ou enviar, o JPG costuma ser melhor, porque o arquivo fica bem menor. Nosso guia sobre [como salvar WebP como JPG](/blog/how-to-save-webp-as-jpg) explica isso.

## Como converter WebP para PNG online e grátis

1. Abra o [conversor grátis de WebP para PNG](/webp-to-png).
2. Solte suas imagens WebP na caixa, ou toque nela para escolher nos seus arquivos ou fotos.
3. Cada imagem é convertida no seu navegador, no seu próprio aparelho. Nada é enviado.
4. Clique em **Baixar**, ou baixe todos os PNGs de uma vez em um ZIP.

O PNG mantém a mesma largura e altura do original, e as partes transparentes continuam transparentes.

## Como converter WebP para PNG no Windows com o Paint

1. Clique com o botão direito no arquivo `.webp` e escolha **Abrir com → Paint**.
2. Clique em **Arquivo → Salvar como → Imagem PNG**.
3. Escolha uma pasta e clique em **Salvar**.

Atenção: o Paint pode não manter a transparência como você espera, e as partes vazadas podem sair preenchidas de branco. Se o fundo é importante, use o conversor online.

## Como converter WebP para PNG no Mac com a Pré-Visualização

1. Dê dois cliques no arquivo `.webp` para abrir na **Pré-Visualização**.
2. Escolha **Arquivo → Exportar**.
3. Em **Formato**, escolha **PNG**.
4. Clique em **Salvar**.

A Pré-Visualização mantém o fundo transparente ao exportar para PNG. Para converter vários arquivos, abra todos juntos, selecione todas as miniaturas na barra lateral e escolha **Arquivo → Exportar Imagens Selecionadas**.

## E as imagens WebP animadas?

Alguns arquivos WebP se mexem, como um GIF. Um PNG só guarda uma imagem parada, então converter um WebP animado para PNG gera um único quadro. Se você quer manter o movimento, use [WebP para GIF](/webp-to-gif).

## Posso só renomear .webp para .png?

Não. Renomear muda apenas o final do nome do arquivo. A imagem lá dentro continua sendo WebP, então muitos programas e sites vão recusar ou dizer que o arquivo está corrompido. Para ter um PNG de verdade, a imagem precisa ser aberta e salva de novo em PNG, que é exatamente o que um conversor faz.

## Se o PNG ficar grande demais

Arquivos PNG feitos a partir de fotos podem ficar pesados. Se um site disser que o arquivo é grande demais, você tem algumas opções:

- Converter para JPG com [WebP para JPG](/webp-to-jpg), se não precisar de transparência.
- Diminuir o PNG com o [compressor de imagem](/compress-image).
- Transformar um PNG que você já tem em um JPG menor com [PNG para JPG](/png-to-jpg).

E se depois você precisar colocar a imagem de volta num site, o [PNG para WebP](/png-to-webp) transforma ela de novo num arquivo pequeno, ideal para a internet. Para entender melhor o formato, leia [o que é um arquivo WebP](/blog/what-is-a-webp-file).
