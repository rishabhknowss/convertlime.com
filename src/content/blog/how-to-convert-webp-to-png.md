## When PNG is the right choice

WebP images can be photos, graphics or animations, so it helps to know which format to convert to. PNG is the best pick when:

- **The image has a transparent background**, such as a logo, sticker or product cut-out.
- **It contains text**, like a screenshot, diagram, chart or social media graphic.
- **You plan to edit it** and do not want quality to drop each time you save.
- **A design tool, slide deck or website builder** asks for PNG.

For a regular photo you just want to share or upload, JPG is usually better because the file is far smaller. Our guide on [how to save WebP as JPG](/blog/how-to-save-webp-as-jpg) covers that.

## How to convert WebP to PNG on Windows with Paint

1. Right-click the `.webp` file and choose **Open with → Paint**.
2. Click **File → Save as → PNG picture**.
3. Choose a folder and click **Save**.

Be aware that Paint may not keep transparency the way you expect: see-through areas can come out filled with white. If the background matters, use the online converter instead.

## How to convert WebP to PNG on a Mac with Preview

1. Double-click the `.webp` file to open it in **Preview**.
2. Choose **File → Export**.
3. Set **Format** to **PNG**.
4. Click **Save**.

Preview keeps transparent backgrounds when exporting to PNG. To convert several files, open them together, select all the thumbnails in the sidebar, and choose **File → Export Selected Images**.

## On iPhone, iPad and Android

Phones can usually display WebP images, but few have a simple "save as PNG" option built in. The easiest way is to open the [WebP to PNG converter](/webp-to-png) in your phone's browser, tap the box, pick the image, and download the PNG. Avoid taking a screenshot: it loses transparency, adds anything else on your screen, and changes the image size.

## What about animated WebP images?

Some WebP files move, like a GIF. A PNG can only hold one still picture, so converting an animated WebP to PNG gives you a single frame. If you want to keep the movement, use [WebP to GIF](/webp-to-gif) instead.

## Can I rename .webp to .png instead?

No. Renaming only changes the ending of the file name. The picture inside is still WebP, so many apps and websites will refuse it or say the file is damaged. To get a true PNG, the image has to be opened and saved again in PNG format, which is what a converter does.

## If the PNG is too large

PNG files from photos can get big. If a website says your file is too large, you have a few options:

- Convert to JPG instead with [WebP to JPG](/webp-to-jpg), if you do not need transparency.
- Shrink the PNG with the [image compressor](/compress-image).
- Turn an existing PNG into a smaller JPG with [PNG to JPG](/png-to-jpg).

And if you later need to put the image back on a website, [PNG to WebP](/png-to-webp) turns it back into a small web-friendly file. To learn more about the format itself, read [what a WebP file is](/blog/what-is-a-webp-file).
