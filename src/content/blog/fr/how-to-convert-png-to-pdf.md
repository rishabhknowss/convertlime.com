Vous pouvez aussi utiliser les outils déjà installés : **Microsoft Print to PDF** sur Windows, **Aperçu** sur Mac et l'app **Fichiers** sur iPhone. Ce guide détaille chaque méthode, explique ce que devient la transparence et comment garder les pages dans le bon ordre.

## Pourquoi transformer des PNG en PDF ?

PNG est le format dans lequel votre ordinateur et votre téléphone enregistrent les **captures d'écran**, et beaucoup d'applis de scan l'utilisent aussi. C'est parfait pour un texte bien net, mais envoyer dix images séparées n'a rien de pratique. Le PDF règle le problème :

- **Un seul fichier au lieu de dix.** Justificatifs de paiement, échanges de messages, tickets de caisse ou pages d'un bail scanné restent ensemble.
- **Les démarches exigent du PDF.** Dossier de location, CAF, banque, candidature ou site administratif : beaucoup n'acceptent que le PDF.
- **Il s'imprime proprement.** Un PDF garde sa taille de page, l'impression ressemble à l'écran.
- **Il s'ouvre partout.** Tous les téléphones, ordinateurs et logiciels de mail affichent un PDF sans rien installer.

## Convertir PNG en PDF dans le navigateur

1. Ouvrez le [convertisseur PNG en PDF](/png-to-pdf).
2. Déposez vos PNG dans le cadre ou cliquez pour les choisir. Vous pouvez aussi coller une capture directement depuis le presse-papiers avec **Ctrl + V** (ou **Cmd + V** sur Mac).
3. Choisissez la taille de page :
   - **Identique à l'image** : chaque page a exactement la taille du PNG. Idéal pour des captures lues à l'écran, car rien n'est réduit.
   - **A4** : format papier standard avec une petite marge. Idéal pour les scans et tout ce que vous allez imprimer ou déposer sur un site administratif. Les grandes images sont ajustées, les petites ne sont pas étirées.
4. Cliquez sur **Télécharger le PDF**. Chaque PNG devient une page d'un seul fichier.

Sans inscription, sans filigrane et sans limite. Le PDF est fabriqué dans votre navigateur : même une capture de votre RIB ou de votre carte d'identité n'est envoyée à aucun serveur. Si vous mélangez PNG, JPG et photos d'iPhone, utilisez plutôt [Image en PDF](/image-to-pdf).

### Garder les pages dans le bon ordre

Les pages apparaissent dans l'ordre où vous ajoutez les fichiers. Quand vous sélectionnez plusieurs PNG d'un coup, ils sont en général triés par nom : renommez-les d'abord, par exemple `01-recto.png`, `02-verso.png`. Si une page se retrouve mal placée, retirez-la avec la **croix** et ajoutez-la de nouveau : elle passera à la fin.

## Que devient la transparence dans un PDF ?

Un PNG peut contenir des zones transparentes, comme un logo ou une signature scannée sans fond. Une page PDF imite le papier, donc ConvertLime pose chaque PNG sur un **fond blanc**. Votre signature ou votre logo restent identiques, simplement sur du blanc au lieu du damier.

Dans le PDF, chaque image est enregistrée en JPG de haute qualité (92 %). Le fichier est ainsi bien plus léger qu'avec les données PNG brutes, et le texte des captures reste net. Si vous avez besoin d'une image transparente, pour un site web par exemple, gardez le PNG.

## Convertir PNG en PDF sur Windows

Windows 10 et 11 intègrent une imprimante virtuelle, **Microsoft Print to PDF** :

1. Dans l'**Explorateur de fichiers**, sélectionnez un PNG, ou maintenez **Ctrl** et cliquez sur plusieurs.
2. Clic droit, puis **Imprimer** (sur Windows 11, d'abord **Afficher d'autres options**).
3. Choisissez **Microsoft Print to PDF** comme imprimante et une disposition comme **Photo pleine page**.
4. Décochez **Ajuster l'image au cadre** pour ne pas couper les bords de la capture.
5. Cliquez sur **Imprimer**, nommez le fichier puis **Enregistrer**.

Le piège : la fenêtre d'impression rogne ou rétrécit souvent les captures larges. Si le texte paraît coupé, passez par le convertisseur en ligne avec **Identique à l'image**.

## Convertir PNG en PDF sur Mac

1. Sélectionnez les PNG dans le Finder, clic droit, **Ouvrir avec → Aperçu**.
2. Faites glisser les vignettes de la barre latérale dans l'ordre voulu.
3. Pour une seule image : **Fichier → Exporter au format PDF**. Pour plusieurs : **Fichier → Imprimer**, ouvrez le menu **PDF** en bas à gauche et choisissez **Enregistrer au format PDF**.

Aperçu est fiable, mais l'impression place chaque image sur une feuille, ce qui peut ajouter des marges blanches autour des captures.

## Convertir PNG en PDF sur iPhone

1. Si vos captures sont dans **Photos**, sélectionnez-les, touchez **Partager** puis **Enregistrer dans Fichiers**.
2. Dans l'app **Fichiers**, touchez **Sélectionner**, cochez les images, puis **Plus** (trois points) et **Créer un PDF**.

Autre astuce : sélectionnez les images dans Photos, **Partager → Imprimer**, puis écartez deux doigts sur l'aperçu pour l'ouvrir en PDF. Les deux méthodes marchent, mais l'ordre est difficile à maîtriser. Dans Safari, le [convertisseur PNG en PDF](/png-to-pdf) vous laisse choisir les images dans l'ordre et enregistrer le PDF dans Fichiers en une fois.

## Alléger le PDF

Un PDF de captures en pleine résolution peut peser plusieurs Mo, et certains formulaires le refusent. Deux solutions rapides :

- Choisissez **A4** : les très grandes images sont réduites pour tenir sur la page.
- Compressez d'abord les PNG avec le [compresseur d'images](/compress-image), puis créez le PDF.
