What is a JFIF file? It is a regular JPEG picture with a `.jfif` ending instead of `.jpg`. JFIF stands for **JPEG File Interchange Format**, which is simply the standard way JPEG pictures are stored. The picture inside is the same as any JPG; Windows just labelled it differently when you saved it. That is why a JFIF file opens fine on your PC but gets rejected by some upload forms that only look for `.jpg` or `.jpeg`.

## Why your pictures save as .jfif

This usually happens on Windows when you right-click a picture in a web browser and choose to save it. Windows keeps a list of which file ending to use for each type of file. For JPEG pictures, that list can point to `.jfif` instead of `.jpg` on some computers, often after another program has changed it. The browser follows that setting, so the download ends with `.jfif`.

Nothing is wrong with the picture. It is the same image, the same quality and the same size in pixels.

## JFIF vs JPG vs JPEG

| | .jfif | .jpg | .jpeg |
| --- | --- | --- | --- |
| Type of picture | JPEG | JPEG | JPEG |
| Quality | Same | Same | Same |
| Opens in browsers and photo apps | Yes | Yes | Yes |
| Accepted by upload forms | Sometimes no | Yes | Yes |
| Where it usually comes from | Windows downloads | Cameras, phones, websites | Some cameras and apps |

`.jpg` and `.jpeg` are completely interchangeable. If you want to switch between those two, use [JPG to JPEG](/jpg-to-jpeg) or [JPEG to JPG](/jpeg-to-jpg).

## Three ways to turn a JFIF file into a JPG

Pick whichever feels easiest. All three give you a normal JPG.

This is the safest option if a website keeps rejecting your file, or if you have a lot of pictures.

2. Drop your JFIF pictures into the box, or tap it to choose them.
3. Each picture is saved as a proper JPG right in your browser. Nothing is uploaded.
4. Click **Download**, or download them all together as a ZIP.

### Method 2: Rename the file

Because a JFIF file already holds a JPEG picture, renaming it usually works.

1. On Windows, open File Explorer and turn on **file name extensions** from the **View** menu so you can see the `.jfif` ending.
2. Right-click the file and choose **Rename**.
3. Change `.jfif` to `.jpg` and press **Enter**.
4. Click **Yes** when Windows warns you about changing the ending.

On a Mac, click the file name in Finder, change the ending to `.jpg`, and confirm with **Use .jpg**.

### Method 3: Save a copy in Paint or Preview

- **Windows:** open the file in Paint, choose **File → Save as → JPEG picture**, and save.
- **Mac:** open the file in Preview, choose **File → Export**, pick **JPEG** as the format, and save.

This saves the picture again, which is fine for one or two files but slow for a whole folder.

## How to stop Windows saving pictures as JFIF

The cause is a single setting in the Windows Registry. Only change it if you are comfortable doing so, because editing the Registry incorrectly can cause problems. If you are unsure, just rename or convert files as they come.

1. Press **Windows + R**, type `regedit`, and press **Enter**.
2. Go to `HKEY_CLASSES_ROOT\MIME\Database\Content Type\image/jpeg`.
3. Double-click the value named **Extension** on the right.
4. Change `.jfif` to `.jpg` and click **OK**.
5. Close the Registry Editor and restart your browser.

New downloads should now save as `.jpg`. Files you already saved stay as `.jfif`, so rename or convert those.

## Do you need PNG or PDF instead?

Sometimes JPG is not what the form asks for:

- **Need a PNG?** Use [JFIF to PNG](/jfif-to-png). Note that a PNG made from a JPEG picture will be larger, and it will not gain a transparent background.
- **Need a document?** Use [JFIF to PDF](/jfif-to-pdf) to put one or more pictures into a single PDF file.
- **File too big?** After converting, run the JPG through the [image compressor](/compress-image), or [resize it to 200KB](/resize-image-to-200kb) if the form gives an exact limit.

## Is a JFIF file safe?

A JFIF file is a picture, like any JPG. The ending itself is not a warning sign; it just reflects a Windows setting. As with any file, only open pictures from people and websites you trust.
