What is an AVIF file? It is an image saved in the **AV1 Image File Format**, a newer picture format built to make web images as small as possible while still looking sharp. If you saved a picture from a website and it ended in `.avif`, the site chose this format so its pages load faster. The catch: some apps, older computers and many upload forms still cannot open AVIF files, so the simplest fix is to turn the image into a JPG.

## Where AVIF files come from

You almost never create an AVIF yourself. They tend to arrive in one of these ways:

- **Saving a picture from a website.** Shopping sites, news sites and blogs often send AVIF images to modern browsers.
- **Downloads from image or stock sites** that offer AVIF as a smaller option.
- **Some phones and cameras** can save photos in AVIF or the related HEIF family, depending on settings.
- **Files sent to you** by someone who saved pictures from the web.

The format was created by the Alliance for Open Media, the same group of tech companies behind the AV1 video format. That is where the name comes from: AVIF uses the same compression that AV1 uses for video, applied to a single still picture.

## Why AVIF files are so small

AVIF packs a lot of picture into very few bytes. Compared with JPG, it keeps smooth skies, skin tones and gradients cleaner at small file sizes, where a JPG would start to look blocky. It also supports things JPG cannot do:

- **Transparent backgrounds**, like a PNG.
- **Richer colour**, including HDR on screens that support it.
- **Animation**, a bit like a GIF but much smaller.

For a website, smaller images mean faster pages. For you, it means a file that some programs do not yet know how to open.

## What is an AVIF file supported by?

Support has grown a lot, but it is still uneven. Here is a general picture:

| Where you open it | Opens AVIF? |
| --- | --- |
| Chrome, Edge, Firefox (current versions) | Yes |
| Safari on recent iPhone, iPad and Mac | Yes |
| Windows 11 Photos app | Usually, sometimes needs the free AV1 extension |
| Older Windows programs and photo viewers | Often no |
| Word, PowerPoint and older photo editors | Often no |
| Job, visa, exam and government upload forms | Usually rejected |
| Printing shops and photo kiosks | Often rejected |

If the place you need the picture is near the bottom of that table, convert it.

## Other ways to open or convert AVIF

You do not always need a converter. Here are the built-in options, with their trade-offs:

- **Open it in your browser.** Drag the AVIF file into a Chrome, Edge, Firefox or Safari window and it will display. That is fine for looking at it, but it does not change the file.
- **Windows Photos.** On Windows 11, double-click the file. If it does not open, install the free *AV1 Video Extension* from the Microsoft Store and try again.
- **Preview on a Mac.** Recent versions of macOS can open AVIF in Preview. From there, **File → Export** lets you choose JPEG and save a copy.
- **Take a screenshot.** It works in a pinch, but you lose quality and the image size changes to whatever fits on your screen. It is a last resort, not a real conversion.

If any of these feel fiddly, the converter above gives you a proper JPG at full size in a few seconds.

## AVIF vs JPG vs WebP

These three formats often get mixed up because they all show up on websites.

| | AVIF | WebP | JPG |
| --- | --- | --- | --- |
| File size | Smallest | Small | Largest of the three |
| Transparent background | Yes | Yes | No |
| Animation | Yes | Yes | No |
| Opens on old computers and apps | Often no | Sometimes no | Yes |
| Accepted by upload forms | Rarely | Sometimes | Almost always |

If you are not sure which one you need, pick JPG. It is the one that just works. You can read more about the middle option in our guide to [what a WebP file is](/blog/what-is-a-webp-file).
